MarbleDeliveryPro v10.0.7 | Beta / Preview
Windows x64
1) Install: run Setup_MarbleDeliveryPro_v10.0.7.exe
2) Portable: extract MarbleDeliveryPro_v10.0.7_Portable.zip and run MarbleDeliveryPro.exe
3) Existing customer database is stored separately under LOCALAPPDATA\MarbleDeliveryPro; installers must not clear it.
4) Default fields are optional, but a completely empty entry will not be saved as a new record.
5) Report preview and export support PDF, Excel, HTML, PNG, JPG and CSV; check dimensions and selected filters first.
6) Source ZIP is the clean public source; does not contain real customer data.
7) Unsigned installer: Windows SmartScreen warning may appear. Verify SHA256SUMS.txt.
