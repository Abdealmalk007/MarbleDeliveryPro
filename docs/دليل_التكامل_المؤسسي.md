# دليل التكامل المؤسسي — الإصدار 10.0.3

يحافظ الإصدار على مركز التكامل الموجود سابقًا، مع Outbox محلي للأحداث لمنع فقد التغييرات عند تعذر الوصول إلى API.

## المبادئ
- قاعدة البيانات المحلية هي المصدر التشغيلي الأول.
- التكامل الخارجي لا يوقف عملية الحفظ المحلية.
- أحداث السجلات تحفظ في `integration_outbox` ويمكن إعادة إرسالها.
- يدعم البرنامج central API / ERP API / notification webhook وفق الإعدادات الحالية.
- زمن الاتصال قابل للضبط، مع تسجيل آخر خطأ وعدد المحاولات.

## هوية النسخة
كل payload تكامل يتضمن رقم إصدار التطبيق ومخطط قاعدة البيانات عند المواضع المدعومة. الإصدار الحالي: 10.0.3، schema: 14.

## المستخدمون
سجل النشاط المحلي يستخدم اسم المستخدم الحالي. لا ترسل كلمات المرور أو password hashes ضمن أحداث التكامل العادية.

## النسخ الاحتياطي
نسخة ZIP المحلية تشمل بيانات الإدارة الجديدة أيضًا: الأدلة، قوالب التقارير، وتعريفات المستخدمين. كلمات المرور محفوظة داخل النسخة كـ PBKDF2 hashes وليست كنص صريح.
