برنامج لإدارة وتسليم أعمال الرخام ومتابعة العقود والعملاء وحالات التسليم ومواعيدها، مع تنظيم المرفقات والتقارير والاستيراد والتصدير.

## النسخة العامة
- قاعدة البيانات غير مضمنة في ملفات البرنامج؛ تنشأ تلقائيًا فارغة عند الاستخدام لأول مرة.
- لا توجد أسماء عملاء أو أرقام جوال أو سجلات تسليم أو موظفين أو ملفات مرفقة أو نسخ احتياطية مُدرجة ضمن الإصدار.
- اسم المنشأة الافتراضي فارغ؛ يدخل المستخدم اسم شركته والشعار والحقول حسب حاجته.
- بيانات المستخدم تحفظ في `%LOCALAPPDATA%\MarbleDeliveryPro` على جهازه.
- تحديث برنامج قديم **لا يمسح بياناته**. الاختبارات على قاعدة مستقلة باستخدام متغير `MARBLE_DELIVERY_DATA_DIR`.
- لا يُسمح بتسجيل الدخول إلى حساب بلا كلمة مرور. عيّن كلمة مرور للمسؤول قبل تفعيل إجبارية تسجيل الدخول.

## وظائف البرنامج
- إضافة وتعديل وأرشفة سجلات تسليم الرخام.
- تخصيص حقول التقارير والجداول.
- استيراد Excel وCSV.
- تصدير PDF وExcel وCSV وصور وتقارير HTML.
- النسخ الاحتياطي والاستعادة وإدارة المرفقات.
- سجل النشاط وتقارير ومتابعة حالات التسليم.
- تكاملات اختيارية مع أنظمة خارجية.

## التحميل والإعداد
- **Setup:** ملف `Setup_MarbleDeliveryPro_v10.0.5.exe`.
- **Portable:** ملف `MarbleDeliveryPro_v10.0.5_Portable.zip`.
- **Source:** شيفرة Python ومهام البناء والاختبارات.

لا تنقل إلى GitHub قاعدة البيانات أو ملفات `backups` أو `attachments` أو السجلات. افحص الملف `SHA256_v10.0.5.txt` للتحقق من سلامة ملفات الإصدار.

## النشر على GitHub
بعد التحقق من ملفات الإصدار، ثبت GitHub CLI ونفذ `gh auth login`، ثم شغّل `PUBLISH_GITHUB.ps1`. يتطلب الأمر كتابة `PUBLISH` لتأكيد إنشاء مستودع عام ونشر ملفات الإصدار، ولا يتم النشر تلقائيًا دون الموافقة.
